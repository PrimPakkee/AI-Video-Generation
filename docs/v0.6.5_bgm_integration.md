# v0.6.5 — 本地 BGM 库 + LLM 选曲 + FFmpeg 同步混音

## 概要

v0.6.5 给 Image Video 路线加上**背景音乐（BGM）**。BGM 不是 AI 生成的——我们维护一个本地 mp3 库（`assets/bgm/`），让 LLM 在写 slide 内容的同一次调用里**根据 art_direction 的情绪挑一首**，然后 FFmpeg 在合成最终 mp4 时把 BGM 混进来。

**TTS 旁白还没接**（计划在 v0.6.6 / v0.6.7）。当前视频音轨里只有 BGM，没有人声。

## 不做的事

- 不调任何 BGM 生成 / TTS / Seedance / APX video API
- LLM 不"听"音频——它只看 manifest 里的文字描述
- 不修改 `.env`
- 不 git add / commit / push

## 用法

### 1. 把 mp3 放进 `assets/bgm/`

要求：
- 文件名只用小写 ASCII + 短横线（`mixkit-foo-bar-baz.mp3`），不要空格 / 逗号 / 中文（FFmpeg concat 会出毛病）
- 操作员手写一份 `assets/bgm/manifest.json` 描述每首曲子

### 2. `manifest.json` 字段

```json
{
  "schema_version": "bgm_manifest_v0.6.5",
  "default_track": "mixkit-classical-3-film-score-hopeful-reflective.mp3",
  "tracks": [
    {
      "filename": "...",
      "display_name": "...",
      "mood_keywords": ["calm", "thoughtful"],
      "fits": "Slow reflective explainers...",
      "tempo": "slow",
      "energy": "low",
      "instruments": "piano, strings"
    }
  ]
}
```

LLM 看这些字段挑曲。`mood_keywords / fits` 写得越准，匹配越准。

### 3. 控制开关

`.env` 里可选：

```
IMAGE_VIDEO_DISABLE_BGM=1                # 关掉 BGM（视频纯静音）
IMAGE_VIDEO_BGM_FORCE=mixkit-...mp3       # 不让 LLM 选，直接用这首
```

默认全打开（`APX_IMAGE2_ENABLED` + `AI_VIDEO_LLM_API_KEY` 配好的情况下）。

## FFmpeg 命令

合成时拼出来的关键参数：

```
ffmpeg -y \
  -f concat -safe 0 -i concat.txt \
  -stream_loop -1 -i bgm.mp3 \
  -filter_complex "[1:a]volume=-15.0dB,afade=t=out:st=29:d=1[a]" \
  -map 0:v -map "[a]" \
  -vf "fps=24,format=yuv420p" \
  -c:v libx264 -pix_fmt yuv420p \
  -c:a aac -b:a 192k \
  -shortest -movflags +faststart \
  final_video.mp4
```

关键决策：

- `-stream_loop -1` 让 BGM 比视频短时无限循环
- `-shortest` 让总输出在视频结束时停止——**视频结束 BGM 也结束**
- `volume=-15dB` 把 BGM 压低（约 18% 音量），等 v0.6.6+ 接 TTS 时旁白能盖过去
- `afade=t=out:st=...:d=1` 最后 1 秒淡出，避免硬切的"咔"
- `aac 192k` 高质量音频，TikTok / Reels / YouTube 都吃

## 输出

`outputs/<slug>/image_video/final_video.mp4` — 现在带 audio stream（之前是纯静音）。

`pipeline_result` / 数据库 metadata / 前端 Generation Evidence 都新增了 BGM 字段：
- `bgm_used` (bool)
- `bgm_filename` / `bgm_display_name`
- `bgm_mood_keywords` (array)
- `bgm_volume_db` (默认 -15)
- `bgm_chosen_by_llm` / `bgm_llm_why`
- `bgm_disabled_by_env` / `bgm_fallback_used` / `bgm_fallback_reason`

前端 Generation Evidence 面板显示三行：
- BGM used: Yes / No
- BGM track: <display_name>
- BGM volume: -15 dB

## 自测命令

```bash
# 默认 smoke（offline，零网络，无 BGM）
python3 scripts/smoke_image_video_pipeline.py

# 带 BGM（仍然 offline，只读 assets/bgm/*.mp3）
python3 scripts/smoke_image_video_pipeline.py --with-bgm

# 全套
python3 scripts/smoke_image_video_pipeline.py --with-llm --with-image2 --with-bgm --full

# 稳定性
python3 scripts/run_stability_checks.py
```

## 浏览器验证清单

1. 重启 uvicorn（让进程发现新的 `web/audio_providers/`）
2. 切到 Video Mode → Image Video → 输入题目 → Generate
3. 进度面板应该出现**第 4 个新阶段**「Select background music」
4. 生成完后 Generation Evidence 显示 `BGM used: Yes / BGM track: <某首> / BGM volume: -15 dB`
5. Video tab 播放视频，能听到背景音乐，**视频结束 BGM 也结束**，没有黑屏多余音频
