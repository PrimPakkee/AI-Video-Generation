**C1. 编辑并保存成功**

- ✅ 不出现空白

**C2. 编辑 Raw Text 空内容保护**

测试步骤:
1. 进入 Raw Text
2. 点击 Edit
3. 全选删除全部内容
4. 点击 Save

验收标准:

- ✅ Save 被拒绝
- ✅ 数据库 prompt_text 不被清空
- ✅ 编辑器仍保留 textarea,可以复制或重新编辑
- ✅ 不退出编辑状态

**C3. 编辑 Raw Text 长度过短保护**

测试步骤:
1. 进入 Raw Text
2. 点击 Edit
3. 全选删除,只保留一小段文字(例如 100 字符)
4. 点击 Save

验收标准:
- ✅ 系统弹出确认对话框:
  ```
  Warning: Raw Text is very short (100 characters).
  This is unusual for a NotebookLM prompt and may indicate accidental deletion.
  Are you sure you want to save this?
  ```
- ✅ 点击 Cancel,保留编辑状态,不保存
- ✅ 点击 OK,强制保存
- ✅ 如果点击 Cancel,数据库不被修改

**C4. 编辑失败后状态恢复**

测试步骤:
1. 进入 Raw Text
2. 点击 Edit
3. 修改内容

5. 点击 Save
6. 观察页面行为

验收标准:
- ✅ 弹出详细错误提示(不是"Unknown error")
- ✅ textarea 内容不被清空
- ✅ 继续停留在编辑状态
- ✅ 用户可以复制内容或重新尝试保存
