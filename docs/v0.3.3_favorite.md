# AI Video Prompt Generator v0.3.3 - Favorite 功能

## 版本信息
- 版本号：v0.3.3
- 发布日期：2025-01-XX
- 功能：新增 Favorite / 收藏功能

## 新增功能

### 1. 收藏系统
- 用户可以收藏重要的题目，方便快速查找
- 收藏状态持久化存储在数据库中
- 支持收藏和取消收藏操作

### 2. Favorites 模式
- 点击 Recent Topics 标题行右侧的星星图标进入 Favorites 模式
- Favorites 模式只显示已收藏的题目
- 支持在 Favorites 模式下搜索
- 可以从 Favorites 模式返回 Recent Topics

### 3. UI 增强
- Recent Topics 标题行新增 Favorite 星星图标
- 已收藏题目在右侧显示星星状态指示器
- 三个点菜单中新增"收藏"/"取消收藏"选项
- Favorites 为空时显示友好的空状态提示

## 数据库变更

### 新增字段
在 `prompt_history` 表中新增以下字段：

```sql
-- 是否收藏
is_favorite INTEGER NOT NULL DEFAULT 0

-- 收藏时间
favorite_at DATETIME NULL
```

### 数据迁移
- 自动检测并添加新字段
- 旧数据兼容：is_favorite = 0, favorite_at = NULL
- 不会删除或清空现有历史数据

## API 变更

### 新增 API 端点

#### 1. POST /api/history/group/{topic_group_id}/favorite
收藏一个题目组

**请求：**
- 无请求体

**响应：**
```json
{
  "success": true,
  "item": {
    "id": 12,
    "topic_group_id": "...",
    "title": "...",
    "is_favorite": true,
    "favorite_at": "2025-01-XX...",
    "version_count": 2
  }
}
```

#### 2. POST /api/history/group/{topic_group_id}/unfavorite
取消收藏一个题目组

**请求：**
- 无请求体

**响应：**
```json
{
  "success": true,
  "item": {
    "id": 12,
    "topic_group_id": "...",
    "title": "...",
    "is_favorite": false,
    "favorite_at": null,
    "version_count": 2
  }
}
```

#### 3. GET /api/favorites
获取收藏列表

**查询参数：**
- `limit` (可选): 最大返回数量，默认 100
- `q` (可选): 搜索关键词

**响应：**
```json
{
  "success": true,
  "items": [
    {
      "id": 12,
      "topic_group_id": "...",
      "title": "...",
      "is_favorite": true,
      "favorite_at": "2025-01-XX...",
      "version_count": 2,
      ...
    }
  ]
}
```

### 现有 API 增强
以下 API 返回数据中新增 `is_favorite` 和 `favorite_at` 字段：
- GET /api/history
- GET /api/history/{id}
- GET /api/history/group/{topic_group_id}/versions

let favoriteItems = [];

### 交互流程

#### 收藏题目
1. 点击三个点菜单
2. 选择"收藏"
3. 题目右侧显示星星图标
4. 题目仍然保留在 Recent Topics 中

#### 取消收藏
1. 点击三个点菜单
2. 选择"取消收藏"
3. 如果在 Favorites 模式，题目从列表消失
4. 如果在 Recent Topics，题目保留但星星图标消失

#### 进入 Favorites 模式
1. 点击标题行右侧星星图标
2. 标题变为 "FAVORITES"
3. 显示返回 Recent 按钮
4. 只显示已收藏题目

#### 返回 Recent Topics
1. 点击 "← Recent" 按钮
2. 标题恢复为 "RECENT TOPICS"
3. 恢复完整历史列表

## 样式设计

### 设计原则
- 低调不抢眼，类似 ChatGPT 风格
- 适配 Light 和 Dark 模式
- 不影响现有 Pin 功能布局

### 颜色方案
- Light 模式：灰色 (#6b7280)
- Dark 模式：浅灰色 (#c5c5c5)
- hover 时略微加深

### 布局
```
[对话图标] [题目文字] [版本徽章] [Pin图标] [Star图标] [三个点]
```

hover 时：
```
[对话图标] [题目文字] [版本徽章] [三个点]
```
Pin 和 Star 向左收缩，三个点出现在最右侧。

## 技术细节

### Repository 层
新增方法：
- `favorite_history_group(db, topic_group_id)` - 收藏题目组
- `unfavorite_history_group(db, topic_group_id)` - 取消收藏题目组
- `list_favorite_records(db, limit, q)` - 获取收藏列表

### 排序逻辑
Favorites 列表排序：
1. favorite_at DESC（收藏时间倒序）
2. created_at DESC（创建时间倒序）

### 版本管理
- 收藏/取消收藏操作应用于整个 topic_group
- 所有版本共享收藏状态
- 列表只显示最新版本

## 已知限制
- Favorites 模式下不支持日期筛选（设计选择）
- 收藏状态仅限于本地数据库，不支持跨设备同步
