# AI Video Prompt Generator v0.3.4 - Prompt View Modes + Overview + Download All

## 版本信息
- 版本号：v0.3.4
- 发布日期：2026-05-XX
- 功能：三种 Prompt 展示模式 + LLM Overview + 当前视图 Copy/Download + Download All

## 新增功能

### 1. 三种 Prompt 展示模式
- **Raw Text**: 显示原始 NotebookLM Prompt，用于复制到 NotebookLM
- **Preview**: 显示结构化预览，用于检查 Prompt 格式是否完整
- **Overview**: 显示中文内容概览，用于快速理解视频设计思路

默认展示 Raw Text，用户可以通过按钮切换。

### 2. LLM 生成 overview_cn
- LLM 在生成 NotebookLM Prompt 时，额外生成一段中文 overview_cn
- 长度：200-400 字
- 内容：自然解释视频设计思路，包括：
  - 围绕什么问题展开
  - 开头如何吸引观众
  - 题面/场景如何设计
  - 核心推理如何展开
  - 画面如何呈现
  - 最终希望观众理解什么
- overview_cn 不写入 notebooklm_clean_source.txt

### 3. 当前视图 Copy/Download
- Copy 按钮：复制当前展示模式的内容
  - Raw Text 模式：复制原始 Prompt
  - Preview 模式：复制结构化预览文本
  - Overview 模式：复制中文概览
- Download 按钮：下载当前展示模式的内容
  - 文件名分别为：{slug}_raw_text.txt、{slug}_preview.txt、{slug}_overview.txt

### 4. Download All 一键打包下载
- 新增 Download All 按钮，位于结果主卡片右上角
- 点击后下载 zip 包，包含三个 txt 文件：
  - raw_text.txt：原始 NotebookLM Prompt
  - preview.txt：结构化预览文本
  - overview.txt：中文内容概览
- zip 文件名：{slug}_prompt_package.zip

## 数据库变更

### 新增字段
在 `prompt_history` 表中新增以下字段：

```sql
-- 中文内容概览
overview_cn TEXT NULL
```

### 数据迁移
- 自动检测并添加新字段
- 旧数据兼容：overview_cn = NULL
- 旧记录打开时使用 fallback overview
- 不会删除或清空现有历史数据

## API 变更

### 现有 API 增强

#### 1. POST /api/generate
返回数据中新增 `overview_cn` 字段：

```json
{
  "success": true,
  "id": 12,
  "history_id": 12,
  "title": "...",
  "slug": "...",
  "prompt": "...",
  "overview_cn": "这个视频围绕...",
  "output_dir": "...",
  "model": "...",
  "mode": "...",
  "created_at": "..."
}
```

#### 2. GET /api/history/{history_id}
返回数据中新增 `overview_cn` 字段。

### 新增 API 端点

#### GET /api/history/{history_id}/download-all
下载完整 Prompt Package（zip 包）

**响应：**
- Content-Type: application/zip
- Content-Disposition: attachment; filename="{slug}_prompt_package.zip"
- zip 包内容：
  - raw_text.txt
  - preview.txt
  - overview.txt

**处理逻辑：**
- 如果 overview_cn 为空，使用 fallback overview
- preview 从 raw_text 解析生成
- 旧记录也可以正常下载

## LLM Prompt 变更

### llm_topic_enhancer.py
在 LLM prompt 的 Required Fields 中新增：

```markdown
- overview_cn: Chinese content overview (200-400 characters), explaining the video design approach naturally. Should cover: what problem the video addresses, how it opens, how the puzzle is designed, how reasoning unfolds, how visuals work, and what viewers should understand. Write in a natural explanatory style, not as a mechanical checklist. Must be specific to this topic, not a generic template.
```

### 验证逻辑
- overview_cn 是 recommended field，不是 required field
- 如果缺失，打印警告但不失败
- 兼容向后兼容旧数据

## 用户体验

### 展示模式切换
1. 默认进入 Raw Text 模式
2. 点击按钮可切换到 Preview 或 Overview
3. 切换时标题同步变化：
   - Raw Text → "NotebookLM Prompt"
   - Preview → "Prompt Preview"
   - Overview → "Content Overview"
4. 切换时外层大框位置和尺寸不变
5. 不重新调用 LLM，不改变历史记录 active 状态

### Preview 模式
显示结构化内容，分为以下 sections：
- BASIC INFO: Title, Topic, Target platform, Target audience, Video length, Core concept
- PROBLEM & ANSWER: Puzzle setup, Question, Correct answer, Wrong intuition
- REASONING: 分步推理内容
- PRODUCTION PLAN: Narration Script, On-screen text, Visual style
- REQUIREMENTS: Important requirements

### Overview 模式
显示中文内容概览，使用中文阅读友好的字体和行距。

## Fallback Overview 逻辑

旧历史记录没有 overview_cn 时，使用 fallback：

### 有 core_concept
```
这个视频围绕「{title}」展开，核心概念是「{core_concept}」。内容会先提出一个反直觉问题，再通过分步推理解释答案。画面上将使用白底线稿和大号英文字幕，帮助观众理解关键逻辑。
```

### 无 core_concept
```
这个视频围绕「{title}」展开。内容会先提出一个适合短视频传播的问题，再通过分步推理解释答案。画面上将使用白底线稿和大号英文字幕，帮助观众理解关键逻辑。
```

## 技术细节

### 后端实现

#### generate_fallback_overview()
生成旧记录的 fallback overview。

#### generate_preview_text()
从 raw_text 解析生成 preview 文本。

#### /api/history/{history_id}/download-all
使用 Python zipfile + io.BytesIO 在内存中生成 zip，返回 StreamingResponse。

### 前端实现

#### parsePromptSections()
使用简单的 markdown parser，识别 `## Section` 格式。

#### generatePreviewHTML()
将 parsed sections 转换为结构化 HTML。

#### switchPromptViewMode()
切换展示模式，更新标题，显示/隐藏对应内容。
