# v0.5.5 — Seedance Provider Contract Adapter (Dry-Run)

> 本版本在 v0.5.4「Video Content Asset Pipeline」之上引入 **Seedance Provider
> Contract Adapter**。该适配器是**只读、dry-run、不联网**的契约层，用来把
> v0.5.4 已经写好的 `provider_request_preview.json` 校验为「未来可被 Seedance
> 接收」的载荷，并落 3 个新的契约文件。**v0.5.5 不接真实 Seedance API、不发起
> 任何网络请求、不生成真实 mp4、不下载真实视频文件、不写入真实视频 URL；真正
> 的 submit / poll / download 留给 v0.6.0。**

---

## 1. 目标

把 Video Mode 「生成」流程从 v0.5.4 的 7 个内容资产 + 1 个 Mock VideoJob
扩展为：

- **10 个内容资产**（其中 9 个真实文件 + 1 个自注册的 manifest 路径）。
- **1 个 dry-run Mock VideoJob**，stage 升级为 `contract_ready`，progress=90。
- **1 个 Provider Contract Summary** 在 Overview 标签里展示契约摘要。
- **4 个新 API 端点**，全部 dry-run（不发出任何真实 HTTP 请求）。

---

## 2. 新增模块

### 2.1 `web/video_providers/seedance_contract_adapter.py`

唯一的新模块，类名 `SeedanceContractAdapter`：

```text
provider_name        = "mock"
future_provider      = "seedance"
network_enabled      = False
```

| 方法 | 功能 |
| --- | --- |
| `validate_provider_request_preview(payload)` | 校验 v0.5.4 `provider_request_preview.json` 是否符合未来 Seedance 接收格式 |
| `build_seedance_payload_preview(payload)` | 构造未来 Seedance 提交载荷预览，**endpoint=null，无 api_key，无 Authorization** |
| `build_lifecycle_preview(payload, validation)` | 构造完整生命周期（submit/poll/download）预览，所有真实步骤标 `blocked_until_v0.6.0` |
| `dry_run_submit(payload)` | 返回 `provider_not_configured`/`contract_ready`，progress=90，**不发起任何 HTTP 调用** |
| `dry_run_poll(provider_job_id)` | 返回 `provider_not_configured`/`poll_blocked_until_v0.6.0` |
| `dry_run_download(provider_job_id)` | 返回 `real_video_downloaded=false`，`result_video_path/result_video_url=null` |

> 安全约束：模块顶层不存在 `requests.post / httpx.post / aiohttp / urllib.request`
> 真实调用；`http://` / `https://` 字符串只作为 `_scan_for_unsafe_strings` 的
> 检测模式，不作为真实 endpoint。

## 5. 后端 API 变化

### 5.1 新增端点

| 端点 | 类型 | 行为 |
| --- | --- | --- |
| `GET /api/video/history/{history_id}/provider-contract` | 只读 | 返回 contract bundle（preview + validation + lifecycle） |
| `POST /api/video/jobs/{job_id}/dry-run-submit` | dry-run | 不发起真实网络请求，返回 contract_ready 状态 |
| `POST /api/video/jobs/{job_id}/dry-run-poll` | dry-run | 返回 `poll_blocked_until_v0.6.0` |
| `POST /api/video/jobs/{job_id}/dry-run-download` | dry-run | 返回 `real_video_downloaded=false` |

### 5.2 修改

- `/api/video/generate` 与 `/api/video/{id}/regenerate` 响应额外携带：
  `seedance_payload_preview`、`provider_contract_validation`、
  `provider_lifecycle_preview`、`provider_contract: { future_provider,
  contract_ready, network_call_performed=false, real_video_generated=false,
  real_video_downloaded=false }`，并把 v0.5.4 的「real video provider is not
  connected」措辞改为 「Seedance contract adapter is ready in v0.5.5.」。
- `/refresh` 在 v0.5.5 仍返回 501，错误信息更新为 v0.5.5 文案。
- `Download All` 的 `metadata.json` 加入 v0.5.5 的字段；zip 中追加上述 3
  个新资产文件。

## 6. 前端变化（Video Mode Overview）

`renderProviderContractSummaryHTML(item)` 渲染独立 `<div
id="provider-contract-summary">` 区块，列出：

1. Future provider — `seedance`
2. Contract status — `contract_ready` / `validation_failed`
3. Network call performed — `false`
4. Real video downloaded — `false`

`refreshProviderContractSummary(historyId)` 在 Video Mode Overview 渲染后异步
拉取 `/api/video/history/{id}/provider-contract` 并把摘要替换为最新值。**前端
不会触发任何真实视频下载或外部 API 调用。**
