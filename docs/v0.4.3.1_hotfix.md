## 修复的严重回归问题

### 问题 1: CSS 变量未定义 ❌→✅

**问题描述**:
- 使用了不存在的 CSS 变量：`--primary-color`, `--primary-hover`, `--text-placeholder`, `--text-primary`
- 导致按钮颜色异常、placeholder 颜色错误、编辑态边框不显示

**修复方案**:
- ✅ `var(--primary-color)` → `var(--btn-primary)`
- ✅ `var(--primary-hover)` → `var(--btn-primary-hover)`
- ✅ `var(--text-placeholder)` → `var(--text-tertiary)`
- ✅ `var(--text-primary)` → `var(--text-main)`

**修复位置**: `web/static/style.css`

### 问题 2: Regenerate 输入框异常滚动条 ❌→✅

**问题描述**:
- Regenerate 输入框内部出现异常滚动条
- 双层边框、双层布局冲突
- 发送按钮位置不居中

**修复方案**:

- ✅ 发送按钮使用 `bottom: 50%; transform: translateY(50%)` 垂直居中

**修复位置**: `web/static/style.css`, `web/static/main.js` (autoResizeRegenerateTextarea)

### 问题 5: Edit 点击后无法编辑 / 页面跳到底部 ❌→✅

**问题描述**:
- 点击 Edit 后经常不能进入编辑状态
- 有时页面直接跳到底部
- 有时点很多次才能输入
- 有时原地没有任何反应

**根本原因**:
1. Edit 按钮点击事件未阻止冒泡，导致 document click outside 逻辑立即触发保存
2. `focus()` 导致页面自动滚动
3. `contentEditable` 不稳定

**修复方案**:

**5.1 阻止事件冒泡**:
```javascript
editBtn.addEventListener('click', (e) => {
    e.preventDefault();
    e.stopPropagation();
    // ...
});
```

**5.2 改进 click outside 逻辑**:
```javascript
// 不在以下区域点击时才保存：
const clickedInsidePromptActions = e.target.closest('.prompt-header-actions');
const clickedInsideVersionSelector = e.target.closest('.version-selector');
const clickedInsideViewModes = e.target.closest('.prompt-view-modes');
```

**5.3 防止页面滚动**:
```javascript
promptContent.focus({ preventScroll: true });
```

**5.4 统一使用 textarea 编辑**:
- 废弃 contentEditable
- 所有 view（Raw / Preview / Overview）编辑时都用 #prompt-content textarea
- 进入编辑模式：将当前 view 内容放入 textarea，显示 textarea，隐藏 preview/overview div
- 退出编辑模式：保存后根据 view 类型重新渲染对应 div

**修复位置**: `web/static/main.js` (enterEditMode, exitEditMode, event listeners)

### 问题 6: loadTopicVersions is not defined ❌→✅

**问题描述**:
- Regenerate 成功后页面报错：`Request failed: loadTopicVersions is not defined`
- 导致 Regenerate 无法正常完成

**根本原因**:
- 项目中没有 `loadTopicVersions` 函数
- 应该调用 `loadAndShowVersionSelector`

**修复方案**:
```javascript
// 错误：
await loadTopicVersions(currentTopicGroupId);

// 修复：
await loadAndShowVersionSelector(currentTopicGroupId, currentHistoryId);
```

**修复位置**: `web/static/main.js` (triggerRegenerate)

---

### 问题 7: 版本切换时内容不同步 ❌→✅

**问题描述**:
- `handleVersionSelect` 只更新了 resultSlug, resultDir, promptContent.value
- Preview / Overview / change_summary_cn 不更新
- 导致切换版本后内容不一致

**修复方案**:
- ✅ 创建统一的 `renderHistoryRecord(item)` 函数
- ✅ 统一更新所有状态：
  - currentHistoryId
  - currentTopicGroupId
  - currentSlug
  - currentVersionNumber
  - currentRawText
  - currentPreviewTextEdited
  - currentPreviewText
  - currentOverviewText
  - currentChangeSummaryText
  - resultSlug
  - resultDir
  - Raw Text / Preview / Overview 内容

**调用位置**:
- `handleHistoryItemClick()` - 点击左侧历史记录
- `handleVersionSelect()` - 切换版本
- `triggerRegenerate()` - Regenerate 成功后

**修复位置**: `web/static/main.js`
