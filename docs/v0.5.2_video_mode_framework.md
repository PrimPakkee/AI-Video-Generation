# v0.5.2 Video Mode 独立框架与播放器界面稳定版

> 范围：v0.5.2
> 版本说明书：本文档描述 Video Mode 独立框架的最终设计与边界，与
> [`docs/prompt_mode_freeze_spec.md`](./prompt_mode_freeze_spec.md) 配合阅读。
> 本版本是 v0.5.x 系列在「框架 + 播放器界面 + UI 稳定性」上的收口版本，取代此前
> v0.5.1 / v0.5.1.2 临时小版本。

## 1. 版本定位

- v0.5.2 是 **Video Mode 独立框架稳定版** —— 提供与 Prompt Mode 并列的页面、
  数据库、API skeleton 与播放器界面框架，并在该框架内修复 tooltip / 不可用提示 /
  跨模式数据隔离等 UI 与边界问题。
- v0.5.2 **不是**完整真实视频生成版：本版本不会向播放器赋任何真实视频 URL，
  也不会调用任何远程视频渲染 / 转码 / 上传服务。
- v0.5.2 **不接 Seedance**，**不接任何真实视频 API**。Video tab 当前只展示
  播放器骨架与「视频源不可用」提示文案。

## 2. Prompt Mode 与 Video Mode 的关系

- **入口**：右上角 Mode Selector 下拉切换。
- **UI 风格一致**：两种模式共享同一套配色、按钮、tooltip、AI Review 渲染组件。
- **数据完全隔离**：两个模式各有独立 SQLite 库，不共享表、不共享会话、不共享
  历史列表。
- **不复用历史**：Video Mode sidebar 不显示 Prompt Mode 历史，反之亦然。
  切换模式会清空当前选中状态并重新加载目标模式的历史。
- **不复用 AI Review**：Prompt Mode AI Review 评分协议与 schema 不被 Video Mode
  调用，Video Mode AI Review 暂以 placeholder 占位（详见 §9）。

## 3. Mode Selector

- 位置：页面右上角，原 `Prompt Mode` badge 被替换为 `mode-selector-btn`。
- 选项：
  - **Prompt Mode** — Generate NotebookLM educational video prompts；
  - **Video Mode** — Educational video framework + companion prompt assets。
- 行为：
  - 当前模式高亮为 active；
  - 点击展开 `mode-dropdown`，点击页面其它区域关闭；
  - 编辑态 / 生成中切换会先弹确认；
  - 切换会清空当前选中、重新加载目标模式的 sidebar 历史，并暂停 / 卸载
    `<video>` 元素，避免跨模式继续播放；
  - 默认进入 **Prompt Mode**。

## 4. Video Mode 数据隔离

| 模式 | 数据库文件 | Engine / Session | 主要 ORM |
| ---- | ---- | ---- | ---- |
| Prompt Mode | `data/prompt_history.db` | `web/db/database.py` (`engine` / `SessionLocal`) | `PromptHistory`, `PromptReview` |
| Video Mode | `data/video_history.db` | `web/db/video_database.py` (`video_engine` / `VideoSessionLocal`) | `VideoHistory` |

- `web/db/video_database.py` 使用独立 declarative base `VideoBase`，与 Prompt Mode `Base` 互不污染。
- `init_video_db()` 仅在 Video Mode 库中执行 `Base.metadata.create_all`，**不创建、不修改、不读写** Prompt Mode 表。
- 所有 `/api/video/*` endpoint 通过 `Depends(get_video_db)` 注入 Video Mode 会话；
  Prompt Mode endpoint 继续通过 `Depends(get_db)` 注入。
- Prompt Mode 的 `prompt_history` / `prompt_reviews` schema 在 v0.5.2 内**不修改任何字段**。
- `data/video_history.db` 与 `data/prompt_history.db` 一致**不入 Git**。

## 5. Video Mode API

`/api/video/*` 后端骨架（`web/app.py` 注册）：

| Method | Path | 说明 |
| ---- | ---- | ---- |
| POST | `/api/video/generate` | 生成 Video Mode 历史记录（复用 Prompt 生成脚本，写入 video DB） |
| GET | `/api/video/history` | 历史列表（最新版本） |
| GET | `/api/video/history/{id}` | 详情（含 prompt / web_copy_text / 等） |
| PATCH | `/api/video/history/{id}` | 编辑 raw / preview / overview / web_copy |
| GET | `/api/video/history/group/{topic_group_id}/versions` | 同主题所有版本 |
| POST | `/api/video/history/{id}/regenerate` | Regenerate 新版本 |
| POST | `/api/video/history/group/{topic_group_id}/rename` | 重命名 topic group |
| POST | `/api/video/history/{id}/pin` 与 `/unpin` | 置顶 / 取消置顶 |
| POST | `/api/video/history/group/{topic_group_id}/favorite` 与 `/unfavorite` | 收藏 / 取消收藏 |
| POST | `/api/video/history/group/{topic_group_id}/trash` 与 `/restore` | 软删除 / 还原 |
| DELETE | `/api/video/history/group/{topic_group_id}/permanent` | 永久删除 |
| GET | `/api/video/trash`、`/api/video/favorites` | 回收站 / 收藏列表 |
| GET | `/api/video/history/{id}/download-all` | 只读 zip：raw / preview / overview / web_copy / metadata |

`/api/video/history/{id}/download-all` 与 Prompt Mode 一致**对数据库零写入**，
包内只含文本与元数据，**不包含**任何 mp4 / mov / 视频 URL / token / API key。

## 6. Video Mode 六个 Tab

Video Mode 下显示 6 个 tab，顺序固定：

1. **Video**（默认）
2. **Web Copy**
3. **Raw Text**
4. **Preview**
5. **Overview**
6. **AI Review**

Prompt Mode 仍保持 4 个 tab（Raw / Preview / Overview / AI Review），
Video / Web Copy tab 通过 `[hidden]` 在 Prompt Mode 下隐藏。

## 7. Video tab

- Video Mode 默认进入 Video tab。
- 当前 Video tab 是**视频播放器占位框架**，由 `video-player-shell` 内嵌
  `<video>` + 中央 `video-center-play` 三角按钮 + 底部 `video-controls` 组成。
- 控件：
  - 播放 / 暂停按钮；
  - 进度条（拖拽 seek）；
  - 当前时间 / 总时长 `mm:ss / mm:ss`；
  - 倍速菜单：`0.5×, 1×, 1.5×, 2×, 3×, 5×`；
  - 音量控件；
  - 全屏按钮（Fullscreen API 作用于 `video-player-shell`）。
- 当 `<video>` **没有 src** 时：
  - 中央三角点击为 no-op（不报错）；
  - 点击播放器空白区域弹出 player-scoped 提示「Video file is not available yet.」；
  - 不会发出任何网络请求。
- v0.5.2 **不会**给播放器赋任何真实视频 URL；切到其它 tab 或切换 App Mode 时
  会暂停并卸载视频元素。

## 8. Web Copy tab

- 用于未来 YouTube / TikTok / Instagram 等平台的标题、description、caption、
  posting copy 草稿。
- 当前能力：
  - 编辑（`#web-copy-edit-textarea`）；
  - 保存（PATCH 至 `/api/video/history/{id}` 的 `web_copy` 字段）；
  - 复制（Copy 按钮 → `getWebCopyPlainText()` 取当前文本）；
  - 下载（Download 按钮 → 下载 `web_copy.txt`）。
- **空内容也可下载**：当 Web Copy 文本为空时，依然下载 placeholder 文案，
  避免「按了按钮没反应」的死路。

## 9. AI Review tab

- Video Mode 当前 AI Review tab **只显示 placeholder**：
  「AI Review for Video Mode is not connected in v0.5.1.2.」（占位文案保留，
  历史延续；不影响 v0.5.2 的功能边界）。
- Video Mode 下**不调用** Prompt Mode 的 `/api/history/{id}/review` 接口。
- 后续真实视频生成接入后，将单独设计 Video Review / 视频质检 prompt，
  与 Prompt Mode AI Review 评分协议解耦。

## 10. Tooltip / UI 修复

- **全局 tooltip portal**：所有 `.icon-button` hover tooltip 使用单例
  `#global-icon-tooltip` 节点。
- **挂载点**：portal 节点直接 `document.body.appendChild`，脱离任何祖先
  容器的 `overflow` / stacking context。
- **定位**：`position: fixed` + `z-index: 2147483647`，由 JS 基于
  `getBoundingClientRect()` 在视口坐标系中算位置，并用 `window.innerWidth`
  做边缘夹紧；`scroll` / `resize` 时统一隐藏，避免陈旧坐标。
- **效果**：tooltip 不再被视频框、内容卡片、结果区、footer、header 或任何
  父容器遮挡。
- **Video tab 不可用提示**：Video tab 下 Edit / Copy / Download 三个图标按钮
  禁用并通过 `data-unavailable-message` 给出明确文案
  （「Video tab cannot be edited.」/「Video content cannot be copied.」/
  「Video file is not available yet. Video source is not available yet.」）。

## 11. Prompt Mode 保护边界

Prompt Mode v0.4.10 在 v0.5.2 内的所有保护**继续生效**（详见
[`docs/prompt_mode_freeze_spec.md`](./prompt_mode_freeze_spec.md)）：

- Prompt Mode 全部既有功能保持不变；
- 不修改 Prompt 生成主提示词；
- 不修改 AI Review 评分标准 / 评分协议 / schema；
- 不修改 NotebookLM Prompt 输出结构；
- 不修改 Prompt Mode Download All 的只读契约（仍包含
  `raw_text.txt` / `preview.txt` / `overview.txt` / `ai_review.md` /
  `metadata.json`，对数据库零写入）；
- 不修改 Prompt Mode 数据库 schema（`prompt_history` / `prompt_reviews` 字段冻结）；
- 不修改 Prompt Mode Raw Text 数据保护逻辑；
- 不修改 Prompt Mode Regenerate / 版本管理 / 收藏 / 置顶 / 回收站逻辑。

  - 引入真实视频文件、缩略图、播放进度持久化等。
- **后续独立 Video Review**：
  - 设计 Video Review / 视频质检 prompt；
  - 与 Prompt Mode AI Review 解耦，使用独立评分协议与 schema；
  - 不复用 Prompt Mode `prompt_reviews` 表，也不引入 `video_review` 表（暂为占位，
    后续按真实视频生成需求独立设计）。
