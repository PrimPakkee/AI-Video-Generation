# v0.5.6 — Seedance Prompt Compiler（Dry-run）

## 0. 总览

v0.5.6 在 v0.5.5 dry-run 契约层之上新增 **Seedance Prompt Compiler**：把
Video Mode 的结构化内容资产（topic_analysis / reasoning / video_script /
storyboard / provider_request_preview）编译成 Seedance 形态的 prompt 包，
为 v0.6.0 首次真实 Seedance 调用提供可直接复用的输入。

**v0.5.6 仍然不接真实 Seedance、不发起任何真实网络请求、不生成 mp4、
不下载视频文件。** 真实 submit / poll / download 仍保留给 v0.6.0。

## 1. 三层 Prompt 架构

| 层 | 来源 | 关注点 |
| --- | --- | --- |
| 内容正确层 | LLM 生成的 topic_analysis、reasoning | 内容准确、答案正确、推理完整 |
| 脚本层 | video_script、storyboard | 单人旁白节奏、镜头划分、字幕节奏 |
| Provider 层（v0.5.6 新增） | SeedancePromptCompiler 输出 | 把上面两层翻译成 Seedance 喜欢吃的 prompt 形态 |

`SeedancePromptCompiler` **不复用 NotebookLM Prompt** 主模板：
NotebookLM 的产出是给「人 + NotebookLM 自己」看的；Seedance prompt 则
是直接给视频生成模型吃的，必须以英文为主、按场景拆段、强约束「单人
旁白、白底线稿、no dialogue」。

## 2. 新增产出

### 2.1 Provider Profile

`config/provider_profiles/seedance.json`：

- `profile_version = "seedance_prompt_profile_v0.5.6"`
- `preferred_prompt_language = "en"`
- `default_duration_seconds = 60`、`default_aspect_ratio = "9:16"`
- `prompt_strategy = "scene_by_scene"`
- `must_include_constraints`（single narrator / no dialogue / no podcast / 白底
  线稿 / 大字号字幕 / 答案必须正确 …）
- `negative_prompt_defaults`（no dialogue / no interview / no podcast / no
  multiple speakers / no logos …）
- `visual_defaults`（白底、黑色线稿、黄色高亮、几乎静止镜头 …）

profile 为静态配置文件，不发起任何真实网络请求。后续可以追加
`config/provider_profiles/kling.json`、`runway.json` 等而不影响 Seedance。

### 2.2 编译器模块

`web/video_providers/seedance_prompt_compiler.py`：

- `SeedancePromptCompiler` 类
  - `compiler_version = "seedance_prompt_compiler_v0.5.6"`
  - `network_enabled = False`，没有任何 `requests/httpx/aiohttp/urllib`
    调用
  - 不导入 NotebookLM Prompt 主模板
- 公开方法：
  - `compile_from_assets(...)` 输入资产 → 输出
    `{seedance_prompt, negative_prompt, seedance_prompt_debug, ...}`
  - `build_seedance_prompt(...)` 生成英文 8-section prompt：
    Video Goal / Visual Style / Narration Mode / Core Explanation /
    Scene-by-scene Storyboard / On-screen Text Rules / Motion /
    Final Constraints
  - `build_negative_prompt(...)` 合并 profile 默认值 + 资产 risk 点 +
    storyboard.negative_constraints + provider_request_preview 中的
    negative_prompt，去重后输出英文逗号分隔字符串
  - `build_debug_payload(...)` 输出 `seedance_prompt_debug_v0.5.6` schema
    的 JSON：包含 compiler_version、profile_version、section_order、
    inputs_present、必含约束、prompt 字符 / 词数等

### 2.3 资产文件

新增三个磁盘资产（写入 `output_dir/video_assets/`）：

| 文件 | 内容 |
| --- | --- |
| `seedance_prompt.txt` | 主 Seedance prompt（英文 + 分章节） |
| `seedance_negative_prompt.txt` | 合并去重后的英文 negative prompt 字符串 |
| `seedance_prompt_debug.json` | 编译过程元数据（`schema=seedance_prompt_debug_v0.5.6`） |

加上 v0.5.5 的 10 个文件，资产清单共 **13 个核心文件**（manifest 自身
+ 可选 `llm_raw_output.txt` 不计入「核心」）。

### 2.4 manifest 与 payload preview 升级

- `generation_manifest.json`：
  - `schema_version = "video_assets_v0.5.6"`
  - `legacy_schema_version = "video_assets_v0.5.5"`
  - 新增 `seedance_prompt_compiler_version`、
    `seedance_prompt_profile_version`、`seedance_prompt_ready`、
    `seedance_prompt_path` 等字段
  - `prompt_source_for_seedance_payload` 标识 payload.prompt 源自
    compiled prompt（编译成功）还是 provider_prompt.txt（fallback）
- `seedance_payload_preview.json`：
  - `schema_version = "seedance_payload_preview_v0.5.6"`
  - `legacy_schema_version = "seedance_payload_preview_v0.5.5"`
  - 新增 `prompt_compiler_version`、`prompt_source`、
    `negative_prompt_source`、`prompt_from_compiler`、
    `negative_prompt_from_compiler`
  - `payload.prompt` 优先使用 compiled `seedance_prompt.txt`；缺失时
    回退到 upstream `provider_request_preview.prompt`，并在
    `warnings` 中记录回退原因

## 3. 集成顺序

`web/video_asset_pipeline.py` 的 `_save_assets()` 在写完
`provider_request_preview.json` 之后、调用 `SeedanceContractAdapter`
之前，先调用 `SeedancePromptCompiler.compile_from_assets(...)`，将
`seedance_prompt` / `seedance_negative_prompt` / `seedance_prompt_debug`
分别落盘，再把 compiled prompt + negative prompt 注入
`adapter.build_seedance_payload_preview(...)`。整个流程仍然完全离线：
没有任何方法发起真实网络请求。

如果编译器抛出异常，pipeline 把告警写入 `warnings`，写入的三个 Seedance
文件为空字符串，payload preview 自动回退到 upstream provider_prompt，
adapter 在 `warnings` 中标注「Compiled Seedance prompt was empty;
payload fell back to provider_prompt」。

  "video_v0.5.6"`，新增 compiler 版本、prompt 路径字段，并保留
  `legacy_export_schema_version = "video_v0.5.5"` 以兼容旧消费者。

## 6. 安全边界

v0.5.6 严格遵守以下边界：

- 不接真实 Seedance API、不新增 `seedance_provider.py`
- 不执行 `requests.post / httpx.post / aiohttp / urllib` 任何真实网络
  调用（自动化检查会扫描整个 `seedance_prompt_compiler.py`）
- 不生成真实 mp4、不下载视频、不写入真实视频 URL
- 不打印或硬编码 API key；不修改 `.env`
- 不修改 Prompt Mode 数据库 schema、主提示词、AI Review 评分标准
- 不新增 video_review / video_reviews 表
- 不新增 Celery / Redis / RQ 等异步任务队列
- 不提交 `data/*.db`、`outputs/`、`.env`

stability check 中 `check_v056_compiler` 共 17+ 子检查，以上所有安全
边界均自动校验。
