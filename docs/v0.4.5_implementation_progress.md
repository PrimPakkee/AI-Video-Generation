  - `mark_review_stale()` - Mark review as stale after edit

### 3. LLM Integration ✅
- **File**: `scripts/llm_topic_enhancer.py`
- Added `review_prompt()` method - Generate AI Review
- Added `_build_review_system_prompt()` - System prompt
- Added `_build_review_user_prompt()` - User prompt with rubric
- Implements 8-dimension evaluation:
  1. Completeness (15%)
  2. Logical Correctness (20%)
  3. NotebookLM Usability (15%)
  4. Visual Directability (10%)
  5. Short-video Suitability (10%)
  6. Single-narrator Compliance (10%)
  7. Educational Clarity (10%)
  8. Risk & Error Control (10%)
