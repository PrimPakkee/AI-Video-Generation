---

### 2. 8 维度自动质检评分

AI Review 基于固定的 8 个评分维度对当前版本的 NotebookLM Prompt 进行结构化评估：

| 维度 | 权重 | 评估要点 |
|------|-----:|----------|
| **Completeness** | 15% | 检查 Prompt 是否包含所有必需模块（title, topic, hook, puzzle, reasoning, narration, visual style 等） |
| **Logical Correctness** | 20% | 检查谜题逻辑、答案、推理步骤、解释是否正确，惩罚数学错误、概念错误、逻辑矛盾 |
| **NotebookLM Usability** | 15% | 检查 Prompt 是否适合作为 NotebookLM 输入（清晰、结构化、可执行，无工程元数据、调试信息） |
| **Visual Directability** | 10% | 检查视觉指导是否充分（白底手绘风格、清晰图表、字幕、场景进度、视觉一致性） |
| **Short-video Suitability** | 10% | 检查是否适合 TikTok / YouTube Shorts / Instagram Reels（强力 hook、紧凑节奏、清晰结尾） |
| **Single-narrator Compliance** | 10% | 检查是否明确要求单人旁白 / 独白，避免对话、访谈、播客、多说话人 |
| **Educational Clarity** | 10% | 检查是否清晰解释核心概念（面向学生、家长、普通短视频观众，易于理解，避免不必要复杂性） |
| **Risk & Error Control** | 10% | 检查是否包含防错措施（避免错误答案、改变谜题条件、视觉矛盾、无关场景、过度装饰、误导性解释） |

**总分**：100 分

**整体评价**：2-3 句英文评价

---

### 3. 五列表格展示

AI Review 以结构化表格形式展示评估结果：

| Criterion | Weight | Evaluation Focus | LLM Score | LLM Comment |
|-----------|-------:|------------------|----------:|-------------|
| Completeness | 15% | 检查 Prompt 是否包含所有必需模块... | 13/15 | The prompt includes most required modules, but the CTA could be clearer. |
| ... | ... | ... | ... | ... |
| **Total Score** | **100%** | - | **89/100** | - |
| **Overall Review** | - | - | - | The prompt is generally strong and suitable for NotebookLM short-video generation. It has clear structure and strong visual constraints, but some reasoning details could be more explicit. |

**表格特点**：
- 第一列：评分维度
- 第二列：权重
- 第三列：该维度的评估要点
- 第四列：LLM 给出的得分
- 第五列：LLM 针对该维度的评价
- 最后两行：Total Score 和 Overall Review

---

### 4. Lazy Generation

AI Review 采用按需生成策略，优化性能和 API 成本：

**生成逻辑**：
1. 用户生成 Prompt 后，默认停留在 Raw Text 视图
2. 用户**第一次点击 AI Review** 时：
   - 如果数据库中已有 review，直接展示
   - 如果没有 review，调用 LLM 生成质检报告
   - 生成完成后保存到数据库
3. 用户**再次点击** AI Review 时：
   - 直接从数据库读取，不重复调用 LLM

**版本隔离**：
- 每个版本的 AI Review 独立保存
- Regenerate 生成新版本后，新版本没有 Review（需用户点击生成）
- Edit 保存后，当前版本的 Review 被标记为 stale（下次点击重新生成）

---

### 5. Copy / Download 支持

AI Review 内容支持复制和下载：

**Copy**：
- 当前展示 AI Review 时，点击 Copy 按钮复制 Review 的 Markdown 格式表格

**Download**：
- 当前展示 AI Review 时，点击 Download 按钮下载 `ai_review.txt`

**Download All**：
- 打包下载现在包含四个文件：
  1. `raw_text.txt`
  2. `preview.txt`
  3. `overview.txt`
  4. `ai_review.txt`（如果 Review 未生成，文件内容为 "AI Review has not been generated yet."）

## 数据库变更

### 新增表：prompt_reviews

```sql
CREATE TABLE prompt_reviews (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    history_id INTEGER NOT NULL,
    review_json TEXT NOT NULL,
    review_markdown TEXT,
    total_score INTEGER NOT NULL,
    status VARCHAR(50) NOT NULL DEFAULT 'active',
    created_at DATETIME NOT NULL,
    updated_at DATETIME NOT NULL
);

CREATE INDEX idx_review_history_id ON prompt_reviews(history_id);
```

**字段说明**：
- `history_id`: 关联的 Prompt 版本 ID
- `review_json`: 完整的 Review 数据（JSON 格式）
- `review_markdown`: Markdown 格式（可选）
- `total_score`: 总分（0-100）
- `status`: 状态（'active' | 'stale'）
- `created_at` / `updated_at`: 时间戳

## API 变更

### 新增端点

#### 1. GET /api/history/{history_id}/review

**功能**: 获取指定版本的 AI Review

**响应（有 Review）**:
```json
{
  "success": true,
  "has_review": true,
  "review": {
    "rows": [...],
    "total_score": 89,
    "overall_review": "..."
  }
}
```

**响应（无 Review）**:
```json
{
  "success": true,
  "has_review": false,
  "review": null
}
```

#### 2. POST /api/history/{history_id}/review

**功能**: 为指定版本生成 AI Review

**响应**:
```json
{
  "success": true,
  "review": {
    "rows": [
      {
        "criterion": "Completeness",
        "weight": "15%",
        "evaluation_focus": "...",
        "max_score": 15,
        "score": 13,
        "llm_score": "13/15",
        "llm_comment": "..."
      },
      ...
    ],
    "total_score": 89,
    "overall_review": "..."
  }
}
```

### 更新端点

#### PATCH /api/history/{history_id}

**新增逻辑**: Edit 保存后，自动将当前版本的 AI Review 标记为 stale

## LLM 调用变更

### 新增方法：review_prompt()

**位置**: `scripts/llm_topic_enhancer.py`

**功能**: 调用 LLM 对 NotebookLM Prompt 进行 8 维度质检评分

**参数**:
- `raw_prompt`: 完整的 NotebookLM Prompt
- `dry_run`: 是否 dry-run

**返回**:
```json
{
  "rows": [...],
  "total_score": 89,
  "overall_review": "..."
}
```

**Prompt 要求**:
- 系统 Prompt 定义专家角色和评估任务
- 用户 Prompt 包含完整的 8 维度评分标准
- 输出必须是严格 JSON，不能包含 Markdown 代码块
- 所有评价必须使用英文
- 每个 score 必须是整数，不超过 max_score
- total_score 必须等于所有 score 之和
