## 修复的严重问题

### 问题: AI Review 调用失败 - No module named 'requests' ❌→✅

**问题描述**:
- AI Review 功能在后端调用 LLM 时失败
- 错误信息：`AI Review generation failed: No module named 'requests'`
- 原因：`scripts/llm_topic_enhancer.py` 中的 `review_prompt()` 方法直接使用 `import requests` 和 `requests.post()`
- `requirements.txt` 中没有包含 `requests` 依赖
- 每个 AI Review 请求都会失败

**根本原因**:
1. `review_prompt()` 方法绕开了项目现有的 OpenAI client 调用逻辑
2. 直接使用 `requests.post()` 调用 LLM API
3. 未复用 `call_llm_api()` 中已有的兼容性处理逻辑（temperature / response_format 自动 retry）
4. 可能继续触发 gpt-5 系列模型不支持 temperature / response_format 的错误

**修复方案**:

#### 1. 新增通用方法：`call_chat_messages_api()`

**位置**: `scripts/llm_topic_enhancer.py`

创建一个通用的 LLM 调用方法，支持自定义 messages 列表：

```python
def call_chat_messages_api(self, messages, temperature=None, require_json=True):
    """
    Call LLM API with custom messages (for AI Review, Regenerate, etc.)
    
    This method reuses the compatibility logic from call_llm_api() but allows
    passing custom messages instead of a single prompt string.
    """
```

**特点**:
- 使用 `openai.OpenAI` client，不使用 `requests`
- 复用 `call_llm_api()` 的兼容性处理逻辑：
  - 自动 retry without temperature（如果模型不支持）
  - 自动 retry without response_format（如果模型不支持）
  - 处理超时错误
  - 处理空响应
- 支持自定义 temperature 参数
- 支持控制是否请求 JSON 输出

#### 2. 重构 `review_prompt()` 方法

```python
def review_prompt(self, raw_prompt, dry_run=False):
    # ...
    # Prepare messages
    messages = [
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": user_prompt}
    ]
    
    try:
        # ✅ 使用复用方法，自动处理兼容性
        response_text = self.call_chat_messages_api(
            messages=messages,
            temperature=0.3,  # Lower for consistent evaluation
            require_json=True
        )
        
        # ✅ 使用 parse_json_response，自动清洗和错误处理
        review_data = self.parse_json_response(response_text)
        
        # ✅ 验证响应结构
        if not isinstance(review_data, dict):
            raise ValueError("AI Review response is not a valid JSON object")
        
        if "rows" not in review_data:
            raise ValueError("AI Review response missing 'rows' field")
        
        return review_data
```

**改进点**:
1. ✅ 移除 `import requests` 依赖
2. ✅ 使用 OpenAI client（通过 `call_chat_messages_api()`）
3. ✅ 自动处理 gpt-5 系列模型不支持 temperature 的情况
4. ✅ 自动处理模型不支持 response_format 的情况
5. ✅ 使用 `parse_json_response()` 清洗 JSON（移除 markdown code fence、提取 JSON 片段）
6. ✅ 添加响应结构验证
7. ✅ 统一错误处理和日志输出
