# Think Academy AI 教育短视频风格指南

## 一、品牌定位

### 核心定位
Think Academy AI 教育短视频是一个面向海外学生和家长的教育内容品牌，通过 **趣味题目 + 可视化推理 + 清晰讲解 + 答案揭晓** 的形式，传递科学思维和学习方法。

### 品牌特点
- 🎯 **教育性**：每条视频必须有明确的知识点和推理过程
- 🧠 **启发性**：激发好奇心，而非直接给答案
- 🎨 **简洁性**：画面干净、图示清晰、逻辑直接
- 🌍 **国际化**：适合海外受众，文化包容，避免地域化元素

### 目标平台
- TikTok
- YouTube Shorts
- Instagram Reels
- 小红书（海外版内容）

### 目标受众
- **主要受众**：12-18 岁海外学生（对数学、科学、逻辑感兴趣）
- **次要受众**：学生家长（关注孩子教育，希望找到优质教育资源）

## 二、内容形式规范

### 2.1 叙事形式：Single Narrator（单人旁白）

**✅ 必须使用：**
- **Single narrator（单人旁白）**
- **Monologue narration（独白讲解）**
- 一个清晰、友好的声音从头到尾讲解

**❌ 禁止使用：**
- ❌ 双人对话（Two-person dialogue）
- ❌ 访谈形式（Interview format）
- ❌ 播客风格（Podcast-style discussion）
- ❌ 多人讨论（Multi-person conversation）
- ❌ 主持人 + 嘉宾（Host + guest format）

**为什么必须单人旁白？**
1. **专注度更高**：观众注意力集中在内容本身，而非对话者之间的互动
2. **逻辑更清晰**：单人讲解可以保持推理过程的连贯性
3. **制作更高效**：不需要设计对话脚本和多人配音
4. **品牌识别度**：统一的旁白风格形成品牌记忆点

**正确示例**：
```
Narrator: "If a coin lands heads 5 times in a row, is tails more likely next? 
Most people say yes. But here's the truth: each coin flip is independent. 
The coin has no memory..."
```

**错误示例**：
```
❌ Person A: "Hey, I have a question for you!"
❌ Person B: "Sure, what is it?"
❌ Person A: "If a coin lands heads 5 times..."
```

### 2.2 视频时长

**标准时长**：30-90 秒
- **30-45 秒**：简单题目（例如：单一概念的视觉错觉）
- **45-60 秒**：中等难度（例如：概率论题目）
- **60-90 秒**：复杂题目（例如：多步推理的逻辑题）

**时长分配建议**：
```
0-3s     Hook（钩子）           - 吸引注意力的问题
3-15s    Problem（题面）        - 完整陈述题目条件
15-40s   Reasoning（推理）      - 逐步讲解推理过程
40-50s   Answer（答案）         - 揭晓答案
50-60s   Takeaway（总结）       - 核心概念 + Call-to-Action
```

### 2.3 视频结构

**标准三幕结构**：

#### 第一幕：Hook（钩子）- 0-3 秒
- 目标：前 3 秒抓住观众注意力
- 方法：用一个反直觉的问题或惊人的事实
- 示例：
  - "99% 的人都会选错这道题！"
  - "连续 5 次正面后，下一次呢？"
  - "你的大脑正在骗你！"

#### 第二幕：Problem + Reasoning（题面 + 推理）- 3-40 秒
- 目标：清晰陈述题目，逐步可视化推理过程
- 方法：分步展示，每步都有对应的画面和字幕
- 示例：
  ```
  Step 1: 展示题目条件（例如：硬币连续 5 次正面）
  Step 2: 提出常见误解（例如："大多数人认为反面更可能"）
  Step 3: 解释正确原理（例如："每次抛硬币都是独立事件"）
  Step 4: 用图示验证（例如：树状图展示每次都是 50%）
  ```

#### 第三幕：Answer + Takeaway（答案 + 总结）- 40-60 秒
- 目标：揭晓答案，强化核心概念
- 方法：大字幕显示答案 + 概念名称 + Call-to-Action
- 示例：
  ```
  "答案：仍然是 50-50"
  "这叫做赌徒谬误（Gambler's Fallacy）"
  "关注我们，学更多反直觉的科学知识！"
  ```

## 三、视觉风格规范

### 3.1 核心原则：White Background + Clean Line Art

**✅ 必须使用：**
- **白色背景**（White background）
- **简洁黑色线稿**（Clean black line art）
- **简单图示**（Simple diagrams）
- **教育风格插图**（Educational-style illustrations）
- **几何图形**（Geometric shapes）

**❌ 禁止使用：**
- ❌ 黑色背景（Dark background）
- ❌ 复杂纹理（Complex textures）
- ❌ 写实照片（Photorealistic images）
- ❌ 恐怖风格（Horror elements）
- ❌ 无关装饰（Irrelevant decorations）
- ❌ 随机人物/动物（Random characters unless relevant）

### 3.2 配色方案

**主色调**：
- 背景：纯白色（#FFFFFF）
- 线稿：黑色（#000000）
- 强调色：蓝色（#0066FF）用于关键信息
- 辅助色：灰色（#666666）用于次要信息

**配色示例**：
```
硬币题目：
- 硬币：黑色线稿 + 白色填充
- "正面" 标记：蓝色
- "反面" 标记：灰色
- 背景：纯白色

概率树状图：
- 树枝：黑色线条
- 节点：蓝色圆圈
- 概率数字：黑色
- 背景：纯白色
```

### 3.3 核心图示一致性

**原则**：同一个物体/概念在整个视频中必须保持一致的视觉呈现。

**示例**：
- **硬币**：始终用简单圆圈 + "H" 和 "T" 表示，银色轮廓，黑色线条
- **人脸**：始终用三点两线（两个点代表眼睛，一个点代表嘴，两条线代表轮廓）
- **概率树**：始终用黑色线条 + 蓝色节点

**错误示例**：
- ❌ 第 1 个镜头硬币是金色的，第 3 个镜头变成银色的
- ❌ 第 2 个镜头人脸是线稿，第 5 个镜头变成卡通脸
- ❌ 第 3 个镜头树状图是垂直的，第 6 个镜头变成水平的

### 3.4 字幕设计

**核心原则：Large & Clear（大而清晰）**

**字幕规范**：
- **字号**：占屏幕高度的 1/5-1/4
- **字体**：无衬线字体（Sans-serif），例如：Arial、Helvetica、Roboto
- **颜色**：白色字 + 黑色描边（或黑色字 + 白色背景框）
- **位置**：屏幕中下部（不要遮挡关键画面）
- **时长**：每句字幕停留 1-2 秒

**字幕内容**：
- 突出关键词：数字、答案、概念名称
- 每个镜头 1-2 句
- 与旁白同步

**示例**：
```
Scene 1: "连续 5 次正面?"        [大字幕，白色字 + 黑色描边]
Scene 2: "下一次更可能反面吗?"   [大字幕，占屏幕 1/4]
Scene 5: "赌徒谬误"              [超大字幕，突出概念名称]
Scene 6: "答案: 仍然 50-50"      [超大字幕，蓝色强调]
```

## 四、推理过程可视化

### 4.1 推理步骤清晰分离

**原则**：每个推理步骤必须有对应的画面和字幕。

**示例（硬币题目）**：
```
Step 1: 题目条件
  画面：5 枚硬币，全部显示正面
  字幕："连续 5 次正面"

Step 2: 常见误解
  画面：问号 + "第 6 次?"
  字幕："大多数人认为反面更可能"

Step 3: 核心原理
  画面：一枚硬币 + "独立事件" 标签
  字幕："每次抛硬币都是独立的"

Step 4: 概率验证
  画面：树状图，每次分支都是 50%-50%
  字幕："正面 50% 反面 50%"

Step 5: 概念名称
  画面："Gambler's Fallacy" 大字
  字幕："赌徒谬误"

Step 6: 答案
  画面：第 6 枚硬币 + "50%-50%" 标记
  字幕："答案: 仍然 50-50"
```

### 4.2 可视化工具推荐

**常用可视化方法**：
- **树状图**（Tree diagram）：适合概率题、决策题
- **维恩图**（Venn diagram）：适合集合题、逻辑题
- **时间线**（Timeline）：适合顺序推理题
- **对比图**（Comparison chart）：适合"A vs B"类题目
- **分步图解**（Step-by-step illustration）：适合几何题、视觉错觉题

## 五、旁白文案规范

### 5.1 语气和节奏

**语气**：
- 轻松（Casual）但专业（Professional）
- 好奇（Curious）但权威（Authoritative）
- 友好（Friendly）但不卖萌（Not overly cute）

**节奏**：
- 英文：每秒 2-3 个单词
- 中文：每秒 3-4 个字
- 在关键信息处放慢
- 在答案揭晓前制造悬念

**示例**：
```
慢速：  "But... here's... the truth."        [制造悬念]
正常：  "Each coin flip is independent."     [陈述事实]
快速：  "Follow for more!"                   [Call-to-Action]
```

### 5.2 文案结构

**标准结构**：
```
1. Hook（钩子）
   "If a coin lands heads 5 times in a row, is tails more likely next?"
   
2. Common Misconception（常见误解）
   "Most people say yes."
   
3. Reveal（揭示）
   "But here's the truth:"
   
4. Explanation（解释）
   "Each coin flip is independent. The coin has no memory. 
    Every single flip is still 50-50."
   
5. Concept Name（概念名称）
   "This mistake? It's called the Gambler's Fallacy."
   
6. Takeaway（总结）
   "Past results don't change future odds."
   
7. Call-to-Action
   "Follow for more mind-bending facts!"
```

### 5.3 禁止内容

**❌ 不要使用：**
- 过度夸张的语气（"INSANE!", "CRAZY!", "MIND-BLOWING!"）
- 重复的废话（"So, um, basically, like..."）
- 文化特定的梗（可能不适合海外受众）
- 过于学术的术语（除非必要）

## 六、质量标准

### 6.1 内容准确性（最高优先级）

**硬性要求**：
- ✅ 答案必须逻辑正确
- ✅ 推理过程必须完整
- ✅ 不能为了传播效果牺牲准确性
- ✅ 引用的数据必须可验证

**检查方法**：
1. 让第三方（数学/科学老师）验证答案
2. 在维基百科、学术论文中查证概念
3. 在评论区公开接受挑战

### 6.2 风格一致性

**检查清单**：
- [ ] 单人旁白（非双人对话）
- [ ] 白底线稿（非黑色背景）
- [ ] 大而清晰的字幕
- [ ] 核心图示前后一致
- [ ] 推理步骤清晰分离
- [ ] 无禁止元素（恐怖风格、复杂背景、无关装饰）

### 6.3 传播效果

**评估指标**：
- 前 3 秒钩子是否足够吸引人？
- 答案是否反直觉、有记忆点？
- 是否有 Call-to-Action？
- 是否适合目标平台（TikTok / YouTube Shorts）？

## 七、参考案例

### 案例 1：优秀示例（The Coin Toss Trap）
**题目**：连续 5 次正面后,下一次更可能反面吗  
**时长**：45 秒  
**亮点**：
- ✅ 单人旁白，清晰友好
- ✅ 白底线稿，硬币图示前后一致
- ✅ 大字幕，突出"50-50"答案
- ✅ 树状图清晰展示每次概率
- ✅ 概念名称（Gambler's Fallacy）明确标注

### 案例 2：需要改进的示例
**问题**：NotebookLM 生成了双人对话  
**原因**：Prompt 中没有明确要求 single narrator  
**解决**：在 Prompt 中强调：
```
CRITICAL: This MUST be a single narrator monologue. 
DO NOT create a dialogue, interview, or podcast format.
```

### 案例 3：需要改进的示例
**问题**：黑色背景，视觉风格不对  
**原因**：Visual Style 描述不够详细  
**解决**：在 Prompt 中明确：
```
Visual Style: White background, clean black line art, simple diagrams.
DO NOT use dark background, complex textures, or photorealistic images.
```

## 八、常见错误与纠正

### 错误 1：双人对话
**表现**：
```
❌ Person A: "Hey, did you know..."
❌ Person B: "No way! Really?"
```
**纠正**：改为单人旁白
```
✅ Narrator: "Here's something that will surprise you..."
```

### 错误 2：黑色背景
**表现**：画面背景是深色或黑色  
**纠正**：在 Prompt 中明确：`White background ONLY. No dark backgrounds.`

### 错误 3：字幕太小
**表现**：字幕只占屏幕 1/10，看不清  
**纠正**：在剪映中手动添加大字幕，字号至少占屏幕 1/5

### 错误 4：核心图示不一致
**表现**：硬币一会儿金色一会儿银色  
**纠正**：在 Prompt 中详细描述图示外观：
```
The coin should always be drawn as a simple circle with "H" on one side 
and "T" on the other, silver color, black outline, consistent throughout.
```

### 错误 5：推理过程跳跃
**表现**：直接从题目跳到答案，缺少推理步骤  
**纠正**：在 Storyboard 中明确设计 3-5 个推理步骤，每步都有画面

## 九、NotebookLM Prompt 风格要求模板

**在每个 NotebookLM Prompt 中必须包含以下段落**：

```markdown
## CRITICAL REQUIREMENTS

### Narration Format
- This MUST be a single narrator monologue
- DO NOT create a dialogue between two or more people
- DO NOT create an interview format
- DO NOT create a podcast-style discussion
- Use ONE clear, friendly voice throughout

### Visual Style
- White background ONLY
- Clean black line art and simple diagrams
- Educational-style illustrations
- DO NOT use dark backgrounds
- DO NOT use complex textures or photorealistic images
- DO NOT use horror elements or irrelevant decorations

### Core Diagram Consistency
- [Describe the main visual element, e.g., "The coin should always be 
  drawn as a simple circle with 'H' on one side and 'T' on the other"]
- Maintain consistent visual representation throughout the video

### On-Screen Text
- Large, clear captions (at least 1/5 of screen height)
- Highlight key numbers, answers, and concept names
- Use white text with black outline OR black text with white background box
```
