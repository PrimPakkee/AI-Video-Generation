# AI Video Prompt Generator v0.4.3 Release Notes

**版本名称**: v0.4.3 Prompt Editing + Regenerate with Feedback + Versioned Change Summary

**发布日期**: 2026-05-21

## 新增功能

### 1. Prompt 编辑功能

用户现在可以直接在结果页编辑 Raw Text / Preview / Overview 内容，并将修改保存到数据库。

**功能细节**：
- 在 Prompt 展示区标题行右侧新增 Edit 图标
- 点击 Edit 进入编辑模式，内容框变为可编辑状态
- Edit 图标变为 Save（对勾）图标
- 支持两种保存方式：
  - 点击 Save 图标保存
  - 点击内容框外部空白区域自动保存
- 三种视图都支持编辑：
  - **Raw Text**: 编辑完整的 NotebookLM Prompt
  - **Preview**: 编辑结构化预览内容
  - **Overview**: 编辑中文内容概览
- 编辑后的内容实时同步到数据库
- Copy / Download / Download All 都使用最新编辑后的内容

**技术实现**：
- 前端：`enterEditMode()` 和 `exitEditMode()` 函数
- 后端：`PATCH /api/history/{history_id}` 端点
- 数据库：新增 `preview_text` 字段存储编辑后的 Preview 内容

---

### 2. Regenerate Prompt 功能

用户可以在结果页底部输入修改意见，系统基于当前 Prompt 和用户反馈重新调用 LLM，生成新的 Prompt 版本。

**功能细节**：
- 在 Prompt 内容框下方新增 "Regenerate Prompt" 区域
- 输入框占位文案：`继续输入更多以优化Prompt`
- 支持 Enter 提交，Shift + Enter 换行
- 生成过程中显示 loading 状态："正在重新生成 Prompt，请稍等..."
- Regenerate 会：
  - 调用 LLM，将当前 Prompt、Overview 和用户反馈一起发送
  - 生成完整的新版本 NotebookLM Prompt
  - 生成新的中文 Overview
  - 生成 change_summary_cn（本次改动说明）
  - 创建新版本（Version N）
- 成功后：
  - 页面自动切换到新版本
  - 显示新版本内容
  - Regenerate 输入框清空
  - 左侧历史记录更新
- 失败后：
  - 显示错误信息
  - 不覆盖旧版本
  - 用户可以再次尝试

**技术实现**：
- 前端：`triggerRegenerate()` 函数
- 后端：`POST /api/history/{history_id}/regenerate` 端点
- LLM：`llm_topic_enhancer.py` 中的 `regenerate_prompt()` 方法
- 数据库：`create_regenerated_version()` 方法创建新版本

---

### 3. 版本改动说明

每次 regenerate 后，LLM 会额外生成一段"本次生成新增或改动的内容"（change_summary_cn），展示在 Overview 内容下方。

**功能细节**：
- Overview 视图分为两部分：
  1. **内容概览**（overview_cn）
  2. **本次生成新增或改动的内容**（change_summary_cn）
- Version 1（首次生成）没有改动说明
- Version 2+ 显示改动说明
- 改动说明是中文，100-300 字符
- 说明内容包括：
  - 本次根据反馈做了什么修改
  - 哪些部分进行了强化
  - 新增了哪些设计
  - 改进了哪些逻辑
- Copy / Download Overview 会包含 overview_cn + change_summary_cn
- Download All zip 中的 overview.txt 也包含完整内容

**技术实现**：
- 数据库：新增 `change_summary_cn` 字段
- LLM：在 regenerate prompt 中要求模型生成 change_summary_cn
- 前端：在 Overview 视图中渲染 change_summary_section

---

## 版本分组逻辑

**已有功能保持不变**：
- 同一题目下的多个版本归到同一个 `topic_group_id`
- 左侧历史记录只显示一个题目条目（最新版本）
- 点击题目条目可以查看该题目的所有版本
- 版本选择器中显示 Version 1 / Version 2 / Version 3...

**新增逻辑**：
- **Edit 当前版本** = 修改当前版本，不创建新版本
- **Regenerate Prompt** = 创建新版本
- 新版本会自动：
  - 继承原版本的 topic_group_id
  - 版本号自动递增
  - 标记 `regenerate_from_history_id`（从哪个版本生成）
  - 保存 `regenerate_feedback`（用户反馈）

## 数据库变更

### 新增字段（v0.4.3）

```sql
ALTER TABLE prompt_history ADD COLUMN preview_text TEXT;
ALTER TABLE prompt_history ADD COLUMN change_summary_cn TEXT;
ALTER TABLE prompt_history ADD COLUMN regenerate_from_history_id INTEGER;
ALTER TABLE prompt_history ADD COLUMN regenerate_feedback TEXT;
```

**字段说明**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `preview_text` | TEXT | 用户编辑后的 Preview 内容（如果为空则动态生成） |
| `change_summary_cn` | TEXT | 本次改动说明（中文，仅 regenerate 版本有） |
| `regenerate_from_history_id` | INTEGER | 从哪个版本 regenerate 来的（追踪版本关系） |
| `regenerate_feedback` | TEXT | 用户提交的 regenerate 反馈 |

**迁移兼容性**：
- 自动迁移：启动时自动执行 `ALTER TABLE` 添加新字段
- 向后兼容：旧记录这些字段为 NULL，不影响现有功能
- 默认值：新字段均为 NULL，按需填充

## API 变更

### 新增端点

#### 1. PATCH /api/history/{history_id}

**功能**: 更新 Prompt 内容（编辑功能）

**请求**：
```json
{
  "view": "raw" | "preview" | "overview",
  "content": "用户编辑后的文本"
}
```

**响应**：
```json
{
  "success": true,
  "history_id": 123,
  "view": "raw",
  "content": "...",
  "updated_at": "2026-05-21T10:30:00"
}
```

#### 2. POST /api/history/{history_id}/regenerate

**功能**: 基于当前版本和用户反馈重新生成

**请求**：
```json
{
  "feedback": "用户输入的修改意见"
}
```

**响应**：
```json
{
  "success": true,
  "history_id": 124,
  "topic_group_id": "abc-123",
  "version_number": 2,
  "title": "题目标题",
  "slug": "新的 slug",
  "output_dir": "outputs/新slug",
  "raw_text": "完整的新 NotebookLM Prompt",
  "preview_text": null,
  "overview_cn": "新的中文概览",
  "change_summary_cn": "本次改动说明",
  "regenerate_feedback": "用户反馈",
  "created_at": "...",
  "updated_at": "..."
}
```

### 更新端点

#### GET /api/history/{history_id}

**新增返回字段**：
```json
{
  "item": {
    ...现有字段...,
    "preview_text": "编辑后的 preview 内容",
    "change_summary_cn": "改动说明",
    "regenerate_feedback": "用户反馈",
    "regenerate_from_history_id": 123
  }
}
```

#### GET /api/history/{history_id}/download-all

**更新逻辑**：
- Preview 优先使用 `preview_text`（如有），否则动态生成
- Overview 包含 `overview_cn` + `change_summary_cn`（如有）

## LLM 调用变更

### 新增方法：`regenerate_prompt()`

**位置**: `scripts/llm_topic_enhancer.py`

**参数**：
- `title`: 题目标题
- `current_raw_text`: 当前完整 NotebookLM Prompt
- `current_overview_cn`: 当前中文概览
- `user_feedback`: 用户反馈
- `output_folder`: 输出目录
- `dry_run`: 是否 dry-run

**返回**：
```json
{
  "title": "题目标题",
  "topic": "题目简述",
  "raw_text": "完整的新 NotebookLM Prompt",
  "overview_cn": "新的中文概览",
  "change_summary_cn": "本次改动说明",
  "core_concept": "核心概念",
  "video_length": "50-60s",
  "target_platform": "TikTok / YouTube Shorts / Instagram Reels",
  "target_audience": "目标观众"
}
```

**Prompt 要求**：
- 必须输出完整的 NotebookLM Prompt，不能只输出修改片段
- 必须保留所有关键约束（single narrator / monologue / 白底手绘风格）
- 必须包含 change_summary_cn 字段
- change_summary_cn 必须是中文，100-300 字符
- 必须是有效的 JSON 格式
