Product Introduction

AI Video Prompt Generator turns educational video ideas into either NotebookLM-ready prompts (Prompt Mode) or end-to-end short videos (Video Mode).

  • Prompt Mode: enter a topic, get a structured NotebookLM prompt to copy.
  • Video Mode: enter a topic, pick Seedance Video or Image Video, get a finished mp4 you can play and download.
  • Seedance Video: APX Seedance 2.0 video generation chain (v0.6.2 prompt quality gate retained).
  • Image Video: gpt-image-2 paper-craft slide images + FFmpeg composition (v0.6.4).

Topic → gpt-5-chat plans slides + writes content → gpt-image-2 paints paper-craft backgrounds → FFmpeg concatenates into a 16:9 mp4 → playback in browser.

  • v0.6.3 ✓ Static Image Video MVP + Generation Method selector + Dark mode fix
  • v0.6.4 ✓ gpt-image-2 paper-craft integration (current)
  • v0.6.5 BGM + TTS narration
  • v0.6.6 Subtitle burn-in + transitions

  • v0.7.x User accounts, cloud deployment, productionization

Help Center

  1. Switch to Prompt Mode in the top-right.
  2. Enter an educational video topic.
  3. Click the arrow button or press Enter.
  4. Copy the generated prompt or download it.
  5. Paste it into NotebookLM to create the video.
  1. Switch to Video Mode in the top-right.
  2. Enter a topic; pick a duration (5/15/30/60/90s) and a generation method.
  3. Click Generate. Watch the per-stage progress fill in.
  4. When done, the Video tab plays the finished mp4. Use Download to save it.
  5. Raw Text holds the per-slide image prompts; Overview holds a Chinese summary of the video.
  • Enter: Generate
  • Shift + Enter: New line in the topic input
  • Esc: Close this Settings dialog
  • "FFmpeg is required" → install ffmpeg (macOS: brew install ffmpeg) and restart the backend.
  • "Prompt quality blocked" → the LLM left placeholders in the Seedance prompt; try a clearer topic or rephrase.
  • Image2 stage stuck → each slide takes 30-60s; with 12 slides at concurrency 4 expect 2-3 minutes.
  • No audio in the video → BGM and TTS are planned for v0.6.5; current videos are silent by design.

Privacy Policy

This is a local prototype. Generated prompts, slide plans, image2 backgrounds, and final mp4 files are stored locally under outputs/.

  • API keys are read from .env at backend startup.
  • Keys never reach the browser.
  • Keys never appear in any output file (slide_plan.json, llm_debug.json, etc.).
  • Keys never appear in API responses or evidence panels — only the boolean "configured" flag is surfaced.
  • data/prompt_history.db — Prompt Mode history.
  • data/video_history.db — Video Mode history (separate database).
  • outputs/<slug>/ — generated assets per topic.
  • .env — your secrets (gitignored).
  • AI_VIDEO_LLM_* (gpt-5-chat) — prompt content + slide content.
  • APX_IMAGE2_* (gpt-image-2) — Image Video slide backgrounds. Disabled by default; enable in .env.
  • APX_VIDEO_* (Seedance) — Seedance Video route. Disabled by default; enable in .env.
  • Do not commit .env to git.
  • Do not paste your API key into any chat or screenshot.
  • Do not commit data/*.db, outputs/, or *.mp4 to git (covered by .gitignore).
