Help Center

  1. Enter an educational video topic.
  2. Click the arrow button or press Enter.
  3. Wait for the prompt to be generated.
  4. Copy or download the NotebookLM prompt.
  5. Paste it into NotebookLM to create the video.
  • Enter: Generate Prompt
  • Shift + Enter: New line
