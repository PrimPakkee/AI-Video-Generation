## 分镜设计原则

### 标准结构（3 幕）
1. **第一幕（0-3s）**: Hook - 吸引注意力的问题
2. **第二幕（3-40s）**: Problem + Reasoning - 题面 + 推理过程
3. **第三幕（40-45s）**: Answer + Takeaway - 答案 + 总结

### 每个镜头必须包含
- **时间范围** (Timestamp)
- **画面描述** (Visual Description) - 英文，供 NotebookLM 使用
- **字幕内容** (On-Screen Text) - 大而清晰
- **旁白对应** (Narration) - 与画面同步的旁白文案

## 视觉风格检查清单

在完成分镜后，检查以下项目：

- [ ] **白色背景**：所有镜头都是白色背景（#FFFFFF）
- [ ] **简洁线稿**：所有图示都是黑色线稿，无复杂纹理
- [ ] **核心图示一致**：主要物体（例如硬币）在所有镜头中外观一致
- [ ] **字幕大而清晰**：每个镜头的字幕占屏幕 1/5-1/3
- [ ] **推理步骤清晰**：每个推理步骤有对应的画面
- [ ] **无禁止元素**：无黑色背景、复杂背景、随机人物/动物
- [ ] **逻辑流畅**：画面顺序与推理顺序一致
